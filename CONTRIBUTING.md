# Contributing

Thanks for helping improve SevenFlow.

## Development

1. Create a branch for your change.
2. Keep changes focused.
3. Run relevant checks before opening a pull request.
4. Avoid committing generated config files or local debug output.

## Commit Messages

Use short, descriptive commit messages. Examples:

- `[BUGFIX] Prevent duplicate calendar imports`
- `[FEATURE] Add task API read endpoint`
- `[TASK] Improve open-source setup`

## Pull Requests

Include:

- what changed
- why it changed
- how you tested it
